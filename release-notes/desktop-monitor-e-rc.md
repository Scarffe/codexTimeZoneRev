# Windows 桌面监控 E1/E2 试用版

解压到新的可写文件夹，双击 Start-Monitor.cmd。账号用量中的“监控设置”集中管理刷新间隔、提醒阈值与开关、桌宠形态及显隐。关闭主窗口继续监控；Stop-Monitor.cmd 正常退出本目录实例。重复启动同目录会恢复该实例。

设置和静音周期保存在本目录 monitor-preferences-v1.json；位置在 pet-position-v1.txt，启动器设置仍在 data/settings.json。当前目录与其他便携版本隔离，不自动导入或覆盖旧版本。提醒摘要不含账号明文；用量缓存只在内存，重启重新查询。

“本轮额度周期不再提醒”分别静音当前账号已知窗口，重置后重新允许提醒。查询失败/缓存过期不会弹低额度提醒；离线数据仅为上次观测。首次查询前无法设置周期静音。

本包不含开发者偏好、运行日志、账号数据或凭据。保留整个旧目录即可回退；不要覆盖 Codex 或阶段 D 目录。本地候选未经公开发布。完整范围与硬件补测边界见 STAGE-E.md。
