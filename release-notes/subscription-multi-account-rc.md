# CodexTimeZone 多账号监控候选版

版本 0.2.4-rc.16+20。本地独立候选，未安装、未替换旧程序、未发布到 GitHub Release。

本次小修移除账号额度及账号总览横条上的重复悬浮详情，保留条内动效、数值和重置时间，以及主动点击“查看数值”的入口；会话图表的悬浮详情继续保留。

## 使用

1. 解压到一个新的可写目录，运行 `Start-Candidate.cmd`。重复启动同一目录会打开已有主窗口。
2. 在“监控总览”添加监控来源，通过官方浏览器完成登录。新增来源与默认 Codex 配置分开保存，不切换当前 Codex 登录。
3. 选择来源查看额度，打开总览对比额度条、重置时间轴和状态；可以将另一个来源固定到托盘。
4. 手动刷新或开启自动刷新。默认每来源两分钟，全局串行；失败独立退避，缓存保留原时间。

程序不发送模型请求，也不需要为监控另外充值 API。登录与额度查询会联网；只有你明确添加/登录或启用查询后才发生相应操作。本地会话统计与账号选择分开，API 测速仍仅提供离线回放。五类图、紧凑仪表盘与精简主题托盘继续保留。

## 数据与边界

`account-sources-v1.json` 保存来源、缓存与选择；`account-profiles/profile-*` 保存 CLI 管理的独立登录状态。凭据使用 Windows 用户文件权限保护，不是加密凭据库；不要分享登录后的完整目录。本干净 ZIP 不带本机凭据、缓存或日志。新来源首版仅查询额度，默认来源的既有 token 汇总可继续使用。

同邮箱来源不会自动合并，不合计账号百分比。默认来源仅观察，不能在这里登录、退出或删除。取消登录会停止本程序的作业，但不能撤销已完成的浏览器授权；移除来源清理本地目录，不代表服务端撤权。CLI 续期可能写回对应凭据目录。

关闭主窗口可继续后台监控；托盘“退出程序”会取消本程序的作业并等待保存。`Stop-Candidate.cmd` 只请求本目录实例退出，不按进程名称清理其他 Codex 或候选版。

顶部标注合成账号的体验程序属于单独测试目录，不使用真实登录；回放和空目录核验不替代真实双账号与续期验收。完整统计口径与提醒规则见 [监控说明](docs/monitoring.md)。
