# Windows E3/E4 鲸鱼动画试用版

解压到新的可写文件夹，双击 Start-Monitor.cmd。重复启动只恢复本目录实例；关闭主窗口继续监控，Stop-Monitor.cmd 正常退出本目录监控。不替换现有 Codex 或其他便携目录。

账号用量 → 监控设置增加“减少动画”。开启后静态显示额度及状态；关闭后待机轻微浮动，刷新时有小气泡，低额度柔和暖色变化。隐藏、暂停、挂起、拖拽或数据不可用时停动画。动画表示监控状态，不表示聊天任务进度；动画不会发起额外用量查询。

设置、提醒去重和位置存储沿用 E1/E2；旧版偏好文件仍可读取。无需 API key。包不含开发者账号、凭据、偏好和运行日志。更新与回退使用完整独立目录，不覆盖既有目录。

STAGE-E34.md 描述动画与稳定性边界；实际测试结果见包外 ACCEPTANCE.md。资源验证为有界短时试验，真实跨屏、混合 DPI 和长时过夜测试仍待后续补测。本版本未公开发布。
