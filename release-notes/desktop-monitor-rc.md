# Codex 时区启动器：Windows 桌面监控候选版

这是本地发布候选版，不是 OpenAI 官方软件。保留原有时区启动、账号用量与 Dream Skin 兼容入口，新增可选的桌面常驻监控。当前只交付 Windows x64；完整验收范围见 `STAGE-D.md`。

## 开始使用

1. 将整个 ZIP 解压到新的、可写的独立文件夹，保留全部 DLL 和 `data` 资源。
2. 双击 `Start-Monitor.cmd` 开启监控：主窗口、托盘与桌宠共享数据，默认每 2 分钟查询额度。完整 token 统计保留在手动查询中。
3. 点击桌宠切换紧凑、展开、边缘形态；按住可见区域拖动。右键可刷新、暂停、隐藏、复位和退出。低额度提醒在桌宠旁显示，不表示当前聊天的任务状态。
4. 关闭主窗口仅隐藏到托盘；`Stop-Monitor.cmd` 才退出当前文件夹下的监控，并等待在途查询清理。

直接双击 `codex_timezone.exe` 则使用原有手动启动器模式，关闭窗口即退出。普通启动不会自动开启监控或修改现有 Codex。重复启动同目录监控会恢复已有实例。

## 设置、隐私与回退

- 启动器设置位于本文件夹的 `data/settings.json`；桌宠位置在 `pet-position-v1.txt`。旧格式设置仍可读取。新目录不会自动导入另一便携目录的设置；需要时在双方均退出后，由你备份并复制这些指定文件，避免复制整份日志目录。旧 LocalAppData 配置迁移沿用原程序行为。
- 本 ZIP 不含开发者账号、设置、位置、诊断日志或凭据。用量缓存与提醒去重仅保留在当前进程；重启会重新查询。无需提供 API key。
- 更新前保留原文件夹。回退时正常退出本候选版，继续使用原文件夹；不要覆盖原目录或整份 `data`。不会更改系统时区、包权限或关闭已有 Codex。
- 真实客户端显示时区、Dream Skin 实际注入、多显示器切换、100%／200% 缩放和休眠唤醒仍有未验收项，不将模拟客户端通过等同于所有实机通过。

## 校验

下载 ZIP 后将其 SHA-256 与随附 `.zip.sha256` 比较。解压后的 `FILES-SHA256.json` 列出文件大小和哈希，`BUILD-INFO.json` 标明源码提交和核心二进制哈希。首次运行后产生设置和日志属于本机运行数据，不应混入下一次发布包。

本阶段没有开机自启、在线素材工坊、多账号切换或自动更新。Windows 之外的桌面层尚未适配。
