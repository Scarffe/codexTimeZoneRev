# 0.2.4-rc.1：单实例修复候选版

解压到新目录，运行 Start-Monitor.cmd。若当前用户已经有启动器运行，会直接打开它的主界面，不再因目录不同增加桌宠。重复启动不会切换现有实例的模式、偏好或版本；旧版已运行时复用旧版并不等于升级。

主窗口头部显示版本。桌面原快捷方式可能仍指向根目录的 0.2.3+4；本候选未覆盖该程序或修改入口。

Stop-Monitor.cmd 只退出本目录的普通监控实例。测试隔离参数 --isolated-instance 不写入正常启动脚本；测试由专用脚本启动并自动清理。若已有其他旧版本，它们不会被强制关闭。

包含阶段 F 的角色与本地透明 PNG 导入功能。不附带第三方角色立绘；图像制作与抠图 skill 本轮仅调研，没有安装依赖或下载模型。
