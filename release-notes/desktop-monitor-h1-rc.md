# H1 会话回合平均吞吐候选版

本机只读会话选择、回合统计卡片、托盘和桌宠摘要。主窗口隐藏后继续采集，重复启动恢复主界面。

请打开主界面“会话回合统计”，刷新列表并选择会话。列表显示时间、工作目录和 ID；不会自动猜测当前对话。选择仅在本次运行有效。

显示的 tokens/s 是**回合平均吞吐**，包含工具和等待，不是模型实时解码速度。当前回合未完成时显示上一完成回合；缺失字段显示不可用。推理 token 单列。

这是独立候选包，不修改现有安装和快捷方式。并行试用请双击 `Start-Trial.cmd`（结束用 `Stop-Trial.cmd`），等价于显式使用 `codex_timezone.exe --desktop-monitor --isolated-instance`；普通启动会优先恢复已有正常实例，因此可能打开旧版界面。

测试脚本会在结束时自动退出自己启动的隔离实例。手动试用结束可使用同目录程序的 `--desktop-monitor --isolated-instance --monitor-exit`，不会退出正常实例。

仅支持本地日志；远程会话需后续适配。完整口径与验证边界见 STAGE-H1.md。
