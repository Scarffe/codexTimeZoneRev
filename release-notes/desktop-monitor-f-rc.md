# 角色入口与本地立绘试用版

解压至新的可写目录，运行 Start-Monitor.cmd。使用 Stop-Monitor.cmd 正常退出本目录实例。

单击或右键桌宠打开快捷菜单，选择“角色与本地立绘”。填写角色名称、作者、服装说明、来源，导入透明 PNG。切换角色只改变外观，仍监控当前 Codex 用量。也可在主窗口的监控设置进入。

图片最大 8 MiB、2048×2048；首版最多保存 50 个角色，立绘为静态显示。资料与图片保存在当前目录 pet-roles；保留该目录可保留自定义角色。恢复“默认鲸鱼”不会删除已有角色。

本包不含第三方二次元素材、私人图片、账号或运行偏好。自行导入有权使用的图片；来源文字不会自动打开或联网。贴近桌宠的自绘交互卡片、动作差分、换装不在本批范围。

本版不替换 Codex 或已有候选程序。阶段 F 的范围见 STAGE-F.md，实际验证记录见包外验收报告。
