# 0.2.4-rc.17+21：六个工作区与明确关注

- 默认仍打开启动器；总览、账号额度、关注收件箱、数据分析和独立 API 均保留页面状态。隐藏页面不接收快捷键、焦点和动画。切页不查询、不启动任务。
- 账号、日志和独立 API 来源分开。数据分析保留额度环、最近耗时线、配置类别点、活动区间、响应组成五类图，各数据角色仍有独立颜色。
- 新增三套可切换风格：默认柔和·雾杉、正蓝的科技·极昼、克制浅金重点的石墨·香槟，各有浅/深色并可跟随系统。风格与明暗分别保存；预览/离线试用仅内存生效。切换不重建控制器、不查询来源或丢弃草稿，标题栏/托盘同步使用该风格。
- 最多 8 个明确关注会话，最多保存 200 条结构化事项。仅依据可核验当前回合完成记录通知；未知/读取错误不推断失败或等待。恢复历史不重发提醒。
- 关注通知使用独立序列与状态，系统点击只打开收件箱。事项保留原路径、会话 ID、回合 ID，即使移除关注也可尝试打开原来源；缺失/变化身份拒绝展示。历史回合完整数据不可用时明确标注。
- 关注和旧所选会话提醒共享开关/静音，启用关注时只有一个提醒所有者。隐藏继续关注，真正退出等待保存；失败可重试。
- 离线试用使用内存默认状态、明确的合成依赖标记及既有拒绝策略。未添加实际账号执行切换、K3 启动/续接或真实 API 执行。

验收边界：Flutter 合成测试和页面渲染记录在独立交付报告。原生 Windows 构建、系统通知实际展示/焦点行为与 GUI 操作由独立受控试用验收；本文不将未运行的验收写成通过。当前 Codex、原始便携程序和既有候选不替换。
