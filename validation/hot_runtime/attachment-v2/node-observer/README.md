# Actual owned Node/libuv observer demonstration

**Source prepared; this subagent has not compiled, injected, or run it.** Root owns compilation and execution. This is restricted to a Node parent created by this invocation of the broker, and that parent's synthetic child. Existing Codex/Desktop processes are outside the controller interface and must never be attached.

From an x64 MSVC Native Tools shell in this directory:

```bat
cl /nologo /std:c++17 /EHsc /W4 /O2 /LD /DUNICODE /D_UNICODE observer_dll.cpp /Fe:owned_node_observer.dll
python run_owned_node_observer.py --receipt C:\absolute\path\owned-node-receipt.json
```

Use an outer broker timeout of 90 seconds because the existing metadata-only locator uses bounded helper processes. The Node executable is fixed to `%USERPROFILE%\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe`, with required SHA-256 `3602f2bb1a10f2cbab4c36886218a33c1ab3db87290e73b033c46c77147d0237`. `--node` accepts only that exact resolved path and hash. `--dll` accepts only this directory's `owned_node_observer.dll`. There is no PID argument, arbitrary target selector, service, persistence, current Codex attach, real credential provider or model request.

The broker launches its unique Popen Node with a new nonce and a minimal environment whitelist: Windows root, a new fixture temp directory, and three CTZ-owned bootstrap fields. It never copies `os.environ` wholesale. Node's parent script announces the child it spawned through a dedicated control stdout; this contains only event/nonce/process/version metadata or final booleans/counts. Raw fake-child stdout stays with the parent's one original reader. The child receives an even smaller environment without the mapping name.

Before the synthetic child emits frames, the broker uses existing `locator_metadata.locate(parentIdentity, childIdentity)` to select the exact parent stdout reader and stdin writer from the child-specific pipe set. The locator's fixed PEB metadata is 32 bytes per child, and it never consumes pipe payload. FileProcessIds membership can include inherited descendants; it is not proof of parent+child exclusivity. The broker validates a unique readable stdout handle by exact stdout-name metadata and uses the locator's exact writable stdin remainder.

Only the retained Popen CreateProcess handle can be used for remote operations. PID, full path, creation time and the shared nonce/generation are checked before and after each operation. The announced child's identity and parent relation are initially verified, and child identity remains pinned until after Stop. Toolhelp enumerates modules only in this owned Node PID. A forwarded local `LoadLibraryW` address is resolved to its actual owning module, then relocated by that owned target module's base. The DLL base comes from the owned module snapshot, never from 32-bit GetExitCodeThread. DLL exports Start/Stop come from the local disk PE export table. A loader timeout leaves the remote path allocation resident until process cleanup rather than freeing memory a loader might still use.

DllMain only disables thread notifications. After LoadLibrary's thread has returned, a separate remote thread invokes exported Start. It opens the broker's nonce-named mapping, checks fixed magic/version/layout, current PID and the bootstrap nonce, then locates and compare-swaps only the main Node executable's ReadFile/GOR imports under restored page protection. This sample's environment bootstrap is available only because the broker just created Node. It does **not** establish how an already-running Desktop could receive new environment variables; such a future adapter needs a separately authorized parameter/bootstrap route.

The hook filters by the positively located parent stdout handle. Existing zero-byte libuv reads remain original operations; completed nonzero ReadFile buffers and successful original GetOverlappedResult completions feed the observer. A one-entry pending map suffices only for this single libuv pipe reader. The hook calls each saved original once, retains original arguments/OVERLAPPED, restores original LastError and hashes completed buffers around parsing. It does not call another stdout ReadFile or IOCP dequeue. Unknown concurrency, map occupancy, queue overflow or oversized completed chunks disable observation and preserve the original reader.

The parser derives from the frozen self-IAT prototype but is a separate new header. It uses fixed 4096-byte chunk/line bounds, 16 root keys and nesting limit 16. It rejects duplicate root keys and embedded NUL in selected identifiers, decodes the fixture's ASCII id escape, and skips unknown values semantically. A fixed local scratch line briefly contains raw input, is zeroed after each line, and is never exported. Only Event `{method enum, typed id}` enters shared IPC; arbitrary params/results, token sentinels and raw lines do not. The hook has no heap growth, IPC write/wait, mutex wait or worker dependency. Broker polling and actual acknowledgment writes occur outside Node. Overload is explicitly fail closed, not lossless.

Shared v1 layout is x64 little-endian, Event size 88, event-array offset 144, mapping size 1552, asserted in C++ and Python. The ring is SPSC: Node publishes an event with an interlocked head update; Python copies it before its aligned x64 tail store. The nonce is ownerGeneration, and monotonic head/tail give the bounded invocation's capture sequence. This is an x64 demonstration, not a portable cross-architecture IPC protocol. A future version 2 can add explicit eventKind/captureSequence/ownerGeneration fields on the **same** channel for finite global status events (thread status, turn started/completed, approval/input request, serverRequest/resolved), with enums/ids/status only. This run implements Refresh only. Unknown version/event/drop/disabled state means coverage unknown. Global pending state is always unproved here; it must never be inferred from mtime, assistant text or event absence. No second listener service is proposed.

The fixture emits 7 initial lines, two valid refresh ids (integer and string), nested fake/duplicate-key distractors and synthetic private-value sentinels in params/results. Params can precede method. Writes are coalesced initially and fragmented later. Broker accepts only the two finite expected typed ids from sanitized IPC, replies through the known duplicated stdin writer using its own low-bit event OVERLAPPED, and never sees original child stdout. The child verifies both acknowledgment shapes before sending continued/done. Node compares the entire original stream's bytes/hash and 9 lines, then remains alive with its child until Stop permits identity checks. The receipt exposes only fixed field names and booleans/counts, not ids, frames, private strings, paths, nonce or hashes.

Stop disables observation and restores only owned IAT entries/page protections. The DLL and shared view remain resident until this owned Node exits; Stop does not claim safe physical DLL unloading. No FreeLibrary exists. The broker then sends only this owned parent's exit control command. Per-run temp directories contain no credentials and are left available for review.

Real/model/credential acceptance remains outside this fixture.
