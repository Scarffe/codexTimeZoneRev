# CodexTimeZone UI work

Before modifying frontend appearance or layout, read `docs/design/DESIGN.md`.
Use `docs/design/UI-ACCEPTANCE.md` to select proportionate checks and record evidence.
Preserve existing functionality, three theme families, localization and reduced-motion preferences unless the user asks otherwise.
Use names for human-facing session identification; retain IDs for routing and copyable details. Do not infer titles from conversation bodies or generate titles through model calls.
Validate Flutter layouts and rendered screenshots, not HTML/CSS lint. Record screenshot dimensions and synthetic/live evidence boundaries.
The current user request takes precedence over historical stage documents.
