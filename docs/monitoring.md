# 监控图表说明

启动器是默认首页。侧栏提供启动器、总览、账号额度、关注与收件箱、数据分析、独立 API 测速六个工作区。数据分析在同一滚动页显示账号额度和四张会话图，独立 API 测速提供隔离的离线回放。桌宠暂停；常规入口中保存的自动监控偏好仍可在后台生效，默认打开启动器不等于关闭监控。离线试用入口会阻断这些采集及公网查询。

## 紧凑仪表盘

窄图标侧栏切换六个常驻工作区；页面保留草稿、选择与滚动位置，隐藏页面不接收焦点、快捷键或动画。账号额度管理与日志分析分开，数据分析页从上到下是额度、会话摘要、最近回合、配置对比、上轮活动、最近响应。后四图在宽窗口采用两列，窗口宽度不超过 620 px 时改为单列；五类图始终在同一滚动页。浅色与深色使用同一信息层次，长说明保留在本文档。

最近耗时默认显示折线，可切换柱图；切换只改变同一组真实耗时的画法。缺失值断开，已知零值保留，取消仍用 × 标识。图上悬停可查看对应标记的读数；键盘及触摸使用“查看数值”。查看数值与悬停提示中的计量值、比例和秒数统一保留两位小数，极小正值可显示“<0.01”；标识、序号、时间戳和元数据项数保持原语义。这里只改变显示，原始值、计算与坐标不变。零宽柱形、不可绘制区间等没有命中面积的数据也使用“查看数值”，不在空白位置猜读数。同一对象成功刷新后提示保留并更新数值；切换会话、指标、来源或对应对象后清理旧提示。

## 轻量交互与外观

鼠标经过控件时有轻微弹性反馈。图表有效正值标记进入时轻弹一次；鼠标停留期间，周围持续出现与对应柱段一致的光晕粒子，从固定边缘向外飘散；粒子使用独立周期，不随液体沿边缘循环。竖柱内部由下向上、横柱由左向右流动。数值端点、堆叠边界、时间位置、折线中心与坐标轴保持原位；装饰限制在图表绘图区，未知、取消和零值不会被动画冒充为有数值。流动周期为 1.25 秒，这是视觉设计参数，不是对 Codex 内部动画速度的精确测量。动画不会触发数据查询或开始测速。

点击窗口内空白或控件均可产生涟漪。波纹以透明装饰经过卡片表面，在应用客户区边界最多反弹两次；每次反射仅保留 35% 的透明度贡献，持续衰减，最后 0.4 秒淡出。最多保留最近两次点击，每次最长三秒，连续点击替换较早装饰，不限制控件实际操作。涟漪不使用模糊；静止指针不会维持动画计时器。它不拦截操作或改变焦点，也不延伸到 Windows 原生标题栏及外部托盘菜单。

设置中的“减少动态效果”复用已有便携偏好。应用设置或系统的减少动画任一生效时，保留静态悬停、焦点与数值查看，关闭动效。鼠标移开或对应图表隐藏后停止图表效果，窗口隐藏后清理所有效果；没有悬停或尚未结束的波纹时不运行动画时钟。离线试用设置仍只作用于测试环境。

浅色采用暖灰而非大片纯白，深色采用柔和石板色，正文和元数据使用更舒展的字号、行距与中文回退字体。生产托盘菜单只保留“打开主窗口 / 立即刷新额度 / 自动刷新 / 退出程序”；菜单底色、边界、选中态和图标跟随窗口主题，支持原生键盘选择、勾选与屏幕阅读器名称。高对比度模式或绘制资源不可用时回退系统菜单。自动刷新以勾选表示状态，额度和会话摘要保留在托盘悬停提示，周期静音等高级操作保留在设置中。

窗口、任务栏、托盘和应用信息入口使用原创 Soft Orbit 时环标记。Windows 11（build 22000 起）原生标题栏颜色可跟随应用深浅主题，系统窗口按钮、拖动、缩放和贴靠由 Windows 保留；不支持的配色属性按系统行为回退。启动器使用独立 Shell 应用身份，现有目标客户端的包身份启动机制保持原有流程。旧版本或旧固定快捷方式的图标缓存不代表新 EXE 资源，试用请使用新目录中的入口。

## 来源与操作

账户额度来自所选监控来源，会话统计来自用户明确选择的本地主会话日志。切换账号只联动额度图，不把该日志自动归属给新账号，也不切换正在运行的 Codex 登录。选择会话即使用既有采集流程，停止按钮只停止该会话采集。列表按日志写入时间排序，不据此推断模型活动；搜索包含标题、项目、完整 ID 和路径。同名会话仍按 path + id 区分，最多列出最近 100 个主会话。当前所选日志不在列表时仍可停止采集。

图表选择仅改变显示，不查询账号、不发送模型请求、不改变会话选择或提醒基线。偏好跨切页、窗口宽度和会话变化保留；重启后恢复默认。账户刷新与会话采集独立，暂停自动额度刷新不会停止会话。

## 账户额度

额度组和窗口来自实际数据。剩余比例为 `100 - usedPercent`，与已用视图均使用 0–100% 标尺。不同窗口不能叠加，也不能换算成剩余 token 数。距重置使用共同的小时标尺；节点/本地选择只改变重置时间标签，不查询数据或修改时区。重置到期显示“到期 · 待查询”，不会自动填满额度。

默认来源的累计 token 与最近一天 token 各自保留实际更新时间和日期，可在额度条的信息入口查看缓存事实，不会重新查询。新增受管来源首版只读取额度。两种 token 汇总不是互斥组成，不能相加画成饼图或堆叠。没有完整每日投影时不制造趋势。缓存失败时保留的图只代表上次观测；来源重新登录或默认来源程序绑定改变会使相应旧缓存失效，其他来源保持独立。

## 多账号来源

Windows 候选版支持添加来源并通过官方浏览器单独登录。先验证本机 CLI 协议、空目录和实际文件凭据存储方式，再允许登录；失败后不回退到默认账号。默认来源仅供观察，不提供登录、退出或删除。新来源登录目录在程序旁 `account-profiles/profile-*`，来源别名、缓存与选择在独立的 `account-sources-v1.json`；不读取或复制现有默认凭据来注册新来源。

账号总览提供独立额度环、重置时间轴和状态，支持按剩余额度或下次重置排序，未知值排在后面。百分比不跨账号相加；相同邮箱也不能证明工作区或配额池相同。主界面选择与托盘固定来源相互独立，托盘“立即刷新额度”刷新固定来源；通知使用别名，完整身份仅在详情查看。

默认每来源两分钟、全局一次查询，重复手动刷新合并，失败来源独立退避。重启保留缓存的原始时间；网络失败是上次观测，认证失效不能冒充满额度。读取历史、首次建立低额度基线和切换来源不补报提醒。目录文件损坏时保留原文件并停止需要持久化的新建/登录等操作。

关闭主窗口与退出程序不同：隐藏时监控和登录任务可继续；真正退出会停止调度、取消本程序持有的作业并等待状态保存。取消不能撤销已在浏览器完成的授权；移除来源只清理该来源的本地受管目录。CLI 凭据可能因登录或自动续期写回，只能承诺不主动切换默认认证，不能把查询称为全过程零写入。实际双账号登录、续期和网络额度验收与合成回放分开记录。

## K3.2 只读能力核验

此阶段未开放账号执行、热切换、任务恢复或模型请求。托管来源查询在 `initialize` 后核对实际 `codexHome`，使用已存在目录的规范化结果进行比较；缺失、类型错误、目录不存在或指向其他目录均返回隔离失败，在 `initialized`、配置和账号读取之前停止。默认观察来源的既有行为不变。

工程核验工具位于 `scripts/read-only-probe`，不属于应用的生产任务接口。独立 stdio 子进程先挂起创建、加入自有 Job，再恢复，明确继承三个管道句柄并清空环境；只接受有界帧和白名单方法。清理必须确认本进程退出、自有 Job 为空及读写线程结束，不能把关闭窗口、终结消息或释放对象当作清理凭证。假进程测试不代表真实认证通过。

固定官方 CLI 的单次独立目录探测观测到 `initialize` 成功、目录一致；管理要求响应未通过严格协议解析，因此没有发送配置或账号读取。该次静态诊断与服务子进程均确认清理，新目录未出现 `auth.json`。这些事实不能证明启动全过程没有访问共享凭据库、联网或写入自己的运行时文件。未保存原始账号、配置、标准错误或凭据内容。

当前 Windows 构建的启动前管理要求优先级、注册表重定向以及静态诊断的认证加载顺序仍缺乏已核验依据。因此官方探针入口会在启动子进程之前返回 `startup_auth_backend_unverified`，没有用户绕过开关。后续需先补足对应固定版本的启动前隔离证明，再重新核验有效文件凭据存储；缺失字段或未知值不能从命令行参数、空目录或配置层推断为 `file`。

本轮已知候选目录中没有已登录的托管来源，实际认证身份连续性为 **未验证**。重复未登录不算身份连续性成功；即使将来 `account/read` 的邮箱、类型和套餐字段相同，也只证明可见字段一致，不能证明稳定账号主体、工作区或额度池相同。不会借用、复制当前 Codex 的默认凭据进行补验。只读 `refreshToken:false` 也不构成全过程零写入或零网络承诺。

rc21 的离线修复保留旧错误码，并附加固定的失败层级与 JSON 类型投影，用于区别解码、响应信封及方法结果结构；不记录原文或未知字段名。官方声明的内层 `requirements:null` 继续接受，外层未知结构不会自动当作空要求。未启用的未来参数模板加入 `--strict-config`，并移除会加载认证的 `--print-startup-config` 预探测。现有官方启动阻断不变，未新增权限或认证路径。

## 最近回合与配置

最近回合先从最新记录中取 8、16 或 64 条，再按旧到新显示“回合顺序”。耗时来自日志终结记录，不是逐回合已核验速度历史。取消显示 ×；未知耗时保留缺口，不能补零。结束状态视图按所选范围统计完成和取消回合数。

配置分组按会话、模型、推理强度与服务层级区分，只画严格投影通过的已核验组。回合均值是 `总输出 token / 总完整回合耗时`，不是各轮速度的算术平均。配置图以同一数值轴的类别点显示每个真实聚合组，不制造逐样本点云；保留所有有效组，不按 Top N 隐藏。当前上轮异常不会自行抹掉仍然有效的历史组。

## 最近完成摘要

摘要、“上轮活动”和“上轮响应”指最近完成回合。当前回合运行或取消时，它们可能来自更早的一轮，不能当作当前取消回合的成果。回合均值只发布 `verifiedTokensPerSecond`，未核验的日志报告值仅在信息对话框中标注查看。

首模型 token 可能属于推理。首 token 等待超过完整回合时不可用；未知不补零。完整回合仍包含工具与等待，减去首 token 等待也不能声称得到了纯生成时长。tokens/s 是回合平均吞吐，不是实时输出速度或纯生成速度。

## 活动与覆盖

区间严格使用日志项起止与现有时间线投影，消息、推理、工具、其他共用相对日志窗口时间轴。边界精度约 1 s；不修补非法偏移或猜位置。同类不连续记录分行保留，不填平中间缺口；最多展示 200 项，并标注省略状态。

分类时长是每个类别内部区间的并集。不同类别可能重叠，不能相加成全回合分配。重叠量是各类并集之和减总体并集，不是实际并发墙钟时长。

覆盖只在严格时间线有效、解释为 approximate、无部分来源、无省略项、coverageValid 为 true、analysis 非 partial，且已观测与未归类能对账完整回合时显示。否则显示“覆盖不可核验”，仍可查看有依据的区间和分类事实。覆盖是近似日志覆盖；**未归类不等于等待**，也不能推断为模型计算或生成。

## 最近响应

先取最新 12 条，再按旧到新显示“响应顺序”。这些响应可能只是回合的一部分，不提供每个响应的开始时间、耗时或速度。

输出已经包含推理。输出构成为“输出减推理 + 推理”；仅当二者均为合法非负整数且推理不大于输出时绘制。推理未知不能补零；已知总输出可以在“总输出 · 含推理”视图单独查看。推理视图只显示已知推理。用量不一致的清单是日志报告事实，不算已核验分解；无法对账时标注“不可核对”。

## 质量、信息与提醒

首次加载、空集合和未知值显示短空态。历史追读期间暂不发布稳定会话图及已核验摘要。会话切换或读取失败时清空旧图；列表刷新失败、读取失败和选择保存失败分别显示。会话只提供“上次读取”事实，没有独立过期阈值，不据此猜测断网或服务超时。

信息按钮在同窗口对话框中查看动态 ID、路径、最近完成身份、读取时间、核验原因、错误和最多 200 条合法活动记录。复制只在明确点击时发生，仅限可见标识与诊断字段。界面不展示 prompt、回答正文、工具命令、认证或密钥，也不导出、上传数据。

总览中的“系统提醒记录”保留最近的旧式提醒文本。旧式所选会话通知仍打开当前选择的数据分析，不声称恢复历史通知来源。新关注通知使用独立序列和状态，不受当前选中会话是否仍运行影响；点击操作系统通知只打开关注收件箱，随后从事项打开其原始路径与会话 ID。后台发布不抢焦点或自动切页。

## 明确关注与收件箱

最多关注 8 个会话，原生日志读取池容量为 16；不会自动关注全部历史。先点击“列出可关注会话”，明确选择并可填写别名。“未读”显示未读事项，“关注中”显示启用的关注，“全部”包括暂停关注与已读事项。仅显示日志能够证明的进行中、已完成、已取消；缺失事件或读取失败保持未知，不能推断等待用户或模型失败。

新建、重启、恢复、日志 epoch 变化后静默建立基线。只有新的当前回合完成记录产生稳定事项，ID 使用关注身份、会话 ID 和回合 ID；取消、旧 last 值、mtime 或 active=false 不会产生完成提醒。暂停/移除会立即使迟到读取失效，既有事项仍保留。已关注且启用的所选会话由关注控制器唯一发送完成提醒，未关注/暂停的所选会话保留旧提醒路径。两者共用会话提醒开关和静音设置。

`session-attention-v1.json` 只保存关注引用、别名、启用状态及最多 200 条结构化事项和已读状态，不保存 prompt、回答、工具命令或凭据。损坏文件保留备份，写入串行；恢复已存未读不会重新发送系统通知。隐藏窗口继续关注；真正退出等待读取结束与保存，保存失败会阻止退出并允许重试。

从事项打开分析始终使用事项原路径与预期会话 ID；路径失效、身份缺失或变化时显示读取错误，不替换为其他会话。分析页保留原回合 ID 上下文；若历史完整样本已不可用或日志前进，图表只显示该来源当前可用观测，不能冒充原回合。切换普通工作区不会触发新的账号查询、日志选择或 API 执行。

## 三套主题与颜色角色

每个百分比窗口使用独立 0–100 环，不能跨窗口或账号求和。最近耗时用线、配置用类别点、活动用区间、响应用非推理与推理组成的堆叠；未知保持缺口，重叠区间不画饼图，推理 token 不重复相加。柔和·雾杉、科技·极昼、石墨·香槟均支持浅色和深色，默认柔和·雾杉。图表定量数据使用各主题的专用数据色；按钮填充、文字、链接与原生勾选使用各主题中经过对比度校验的控件颜色，装饰色仅用于小面积强调，不能用浅香槟色替代可读的小字或勾选。减少动态效果与精确数值检查继续生效。

离线试用默认使用内存状态和拒绝真实读取的 backend；只有明确标记的纯合成会话依赖可注入。合成截图与回放不替代真实账号、原生通知呈现或焦点验收；这些结果在验收报告中单独记录。

候选包中的“监控说明”只打开当前 EXE 同目录 `docs/monitoring.md`，不打开网络页面、不发起账号或模型请求。文件缺失时在本地显示原因。旧阶段文档和旧候选包保留其历史身份，不代表本候选行为。

## 独立测速：离线回放

当前独立测速只允许内置 Chat Completions / Responses 合成场景，通过程序拥有的随机本机回环 HTTP 端口，经过实际 HTTP、SSE、协议解析和指标计算链路。无需 API 余额或额外服务；不查询密钥、不连接服务商、不重定向、不重试。公开原生接口也拒绝 `mode:live`，不能通过偏好或开关启用。

切页、恢复记录、选择协议、读取场景和唤醒都不会开始回放。只有点击开始才创建作业，同时最多一个。每个作业固定协议与场景，运行中不能更改其来源；独立回放结果不进入当前会话、账户用量或结束提醒。

数值来自本地客户端单调时钟和协议报告的 token 用量。输出 token 已包含推理，不能再加一次；事件数、字符数不当作 token 数。首模型输出可能是推理，首可见输出是另一时间点。流式速率通常缺少精确的首 token 数量或完整内容边界，即使能够计算也标为估计。推理或工具边界无法对齐、缺少用量、只在最终快照出现文本时，相关速率不可用；不会用零填充未知值。

时间图只画观测事件的位置，不将它们切分成互斥的模型、网络和等待耗时。首 token 前的等待可能同时受排队、网络、服务处理和日志/传输影响；本程序没有依据将它扣除后称为纯模型生成速度，也不能用回放消除真实网络延迟、抖动或丢包影响。回放指标只验证本地功能链路，不是当前 Codex 或任何服务商的性能。

协议完成不等于 HTTP 已结束：成功样本必须同时通过协议、用量、传输结束检查。取消、失败、休眠中断和截断不会产生有效吞吐；已观察到的延迟、用量等事实可能仍保留。退出会停止自有作业并等待有界清理；清理未确认时明确显示，不冒充已完成。

便携目录中的 `benchmark-state-v1.json` 仅保存白名单选择项和上次观察的指标、来源、状态及时间点，不保存 URL、密钥、prompt、回答或任意错误正文。开始请求前先落盘开始意图；保存失败不创建作业。重启后未完成记录标为“已中断”，不自动续跑；恢复卡片是上次保存观察，并不保证保存了退出前每个事件。已完成记录保留其完成事实，未确认的旧进程资源状态不会变成新进程拥有的作业。

`Start-Trial.cmd` 设置的 `--offline-benchmark-trial` 只作用于测试进程：公网/PAC 查询、账户刷新、真实会话读取、启动/修复目标客户端等操作均被阻断，测试数据保存在解压目录内，不加载或改写全局偏好。正常程序入口与该离线试用入口的采集策略不同。


## 外观：三套风格与独立明暗

右上角“主题”菜单包含“配色风格”和“明暗模式”两组。默认柔和·雾杉，采用低亮度中性底与蓝绿重点；科技·极昼采用冷灰与明确正蓝；石墨·香槟采用石墨/暖灰底与少量浅香槟重点。每套均可独立使用跟随系统、浅色或深色，更换风格不会改变明暗选择。

正常入口使用既有 Flutter 偏好保存风格和明暗，旧版没有风格记录时使用雾杉。离线试用和预览仅在内存切换，不读取或改写全局外观偏好。切换不创建查询或测速作业，保留账号来源、所选日志、关注基线、滚动和草稿。

正文、设置、弹出菜单、原生标题栏与托盘菜单使用同一风格角色。香槟浅色操作使用浅金底与深墨字；链接、勾选线与小图标使用可读深色。图表的蓝、紫、绿与中性色仍分别表达数据，配色不改变五类图的含义、未知标记或各来源边界。减少动画设置继续生效。
