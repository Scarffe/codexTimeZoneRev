# 监控图表说明

启动器是默认首页。“监控与工具 → 当前会话”在同一滚动页显示账户额度和四张会话图。独立 API 页面仍待实现，不发送测试请求。桌宠暂停；保存的自动监控偏好仍可在后台生效，默认打开启动器不等于关闭监控。

## 来源与操作

账户额度来自现有账号查询，会话统计来自用户明确选择的本地主会话日志。选择会话即使用既有采集流程，停止按钮只停止该会话采集。列表按日志写入时间排序，不据此推断模型活动；搜索包含标题、项目、完整 ID 和路径。同名会话仍按 path + id 区分，最多列出最近 100 个主会话。当前所选日志不在列表时仍可停止采集。

图表选择仅改变显示，不查询账号、不发送模型请求、不改变会话选择或提醒基线。偏好跨切页、窗口宽度和会话变化保留；重启后恢复默认。账户刷新与会话采集独立，暂停自动额度刷新不会停止会话。

## 账户额度

额度组和窗口来自实际数据。剩余比例为 `100 - usedPercent`，与已用视图均使用 0–100% 标尺。不同窗口不能叠加，也不能换算成剩余 token 数。距重置使用共同的小时标尺；节点/本地选择只改变重置时间标签，不查询数据或修改时区。重置到期显示“到期 · 待查询”，不会自动填满额度。

累计 token 与最近一天 token 各自保留实际更新时间和日期，两者不是互斥组成，不能相加画成饼图或堆叠。没有完整每日投影时不制造趋势。缓存失败时保留的图只代表上次观测；账号或程序来源变化会清除原账号缓存。

## 最近回合与配置

最近回合先从最新记录中取 8、16 或 64 条，再按旧到新显示“回合顺序”。耗时来自日志终结记录，不是逐回合已核验速度历史。取消显示 ×；未知耗时保留缺口，不能补零。结束状态视图按所选范围统计完成和取消回合数。

配置分组按会话、模型、推理强度与服务层级区分，只画严格投影通过的已核验组。回合均值是 `总输出 token / 总完整回合耗时`，不是各轮速度的算术平均。配置图保留所有有效组，不按 Top N 隐藏。当前上轮异常不会自行抹掉仍然有效的历史组。

## 最近完成摘要

摘要、“上轮活动”和“上轮响应”指最近完成回合。当前回合运行或取消时，它们可能来自更早的一轮，不能当作当前取消回合的成果。回合均值只发布 `verifiedTokensPerSecond`，未核验的日志报告值仅在信息对话框中标注查看。

首模型 token 可能属于推理。首 token 等待超过完整回合时不可用；未知不补零。完整回合仍包含工具与等待，减去首 token 等待也不能声称得到了纯生成时长。tokens/s 是回合平均吞吐，不是实时输出速度或纯生成速度。

## 活动与覆盖

区间严格使用日志项起止与现有时间线投影，消息、推理、工具、其他共用相对日志窗口时间轴。边界精度约 1 s；不修补非法偏移或猜位置。同类不连续记录分行保留，不填平中间缺口；最多展示 200 项，并标注省略状态。

分类时长是每个类别内部区间的并集。不同类别可能重叠，不能相加成全回合分配。重叠量是各类并集之和减总体并集，不是实际并发墙钟时长。

覆盖只在严格时间线有效、解释为 approximate、无部分来源、无省略项、coverageValid 为 true、analysis 非 partial，且已观测与未归类能对账完整回合时显示。否则显示“覆盖不可核验”，仍可查看有依据的区间和分类事实。覆盖是近似日志覆盖；**未归类不等于等待**，也不能推断为模型计算或生成。

## 最近响应

先取最新 12 条，再按旧到新显示“响应顺序”。这些响应可能只是回合的一部分，不提供每个响应的开始时间、耗时或速度。

输出已经包含推理。输出构成为“输出减推理 + 推理”；仅当二者均为合法非负整数且推理不大于输出时绘制。推理未知不能补零；已知总输出可以在“总输出 · 含推理”视图单独查看。推理视图只显示已知推理。用量不一致的清单是日志报告事实，不算已核验分解；无法对账时标注“不可核对”。

## 质量、信息与提醒

首次加载、空集合和未知值显示短空态。历史追读期间暂不发布稳定会话图及已核验摘要。会话切换或读取失败时清空旧图；列表刷新失败、读取失败和选择保存失败分别显示。会话只提供“上次读取”事实，没有独立过期阈值，不据此猜测断网或服务超时。

信息按钮在同窗口对话框中查看动态 ID、路径、最近完成身份、读取时间、核验原因、错误和最多 200 条合法活动记录。复制只在明确点击时发生，仅限可见标识与诊断字段。界面不展示 prompt、回答正文、工具命令、认证或密钥，也不导出、上传数据。

“历史提醒”是内存中的最近提醒文本，不是当前所选会话的完成证明。通知只携带定位类别：点击旧通知会定位当前选择，不恢复发生提醒时的旧会话。后台提醒不抢焦点或自动切页。切换来源、图形与指标不会重置或补发历史提醒。

候选包中的“监控说明”只打开当前 EXE 同目录 `docs/monitoring.md`，不打开网络页面、不发起账号或模型请求。文件缺失时在本地显示原因。旧阶段文档和旧候选包保留其历史身份，不代表本候选行为。
